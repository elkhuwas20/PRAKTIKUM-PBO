================================================================================

1. Buka folder "PROJEK"
2. Double-click file "index.html"
3. Website akan terbuka di browser

ATAU menggunakan Live Server (Recommended):
1. Install VS Code extension "Live Server"
2. Right-click "index.html"
3. Pilih "Open with Live Server"

================================================================================
                           DATA STORAGE
================================================================================

Semua data disimpan di localStorage browser:

users           → Data mahasiswa & dosen
prestasi        → Prestasi yang diajukan
proyek          → Proyek kolaborasi
notifikasi      → Notifikasi user

RESET DATA:
Buka Console browser (F12) dan ketik:
localStorage.clear();
sessionStorage.clear();
